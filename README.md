# MadJag Studios plugins

Claude Code plugins from MadJag Studios.

## Install

```
/plugin marketplace add madjagstudios/plugins
/plugin install podium@madjagstudios
```

Then restart Claude Code.

| Plugin | What it does |
|---|---|
| [podium](https://github.com/madjagstudios/podium) | Hand work to any agent CLI on your machine and see and control it from one pane. |

Each plugin's version is pinned to a release tag in `.claude-plugin/marketplace.json`.
